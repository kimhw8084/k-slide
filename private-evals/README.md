# Private evaluation protocol

This directory is a documented shape only. Do not commit Samsung or other
confidential source material, bilingual gold, transcripts, or rendered output.

An approved internal evaluation environment may use:

```text
private-evals/
  manifests/
  source/
  gold/
  results/
```

Gold review should capture critical facts, numbers, dates, units, commitment
state, table geometry, terminology, visual relationships, and comprehension
questions. Keep the held-out set access-controlled and separate from prompt or
threshold tuning.
