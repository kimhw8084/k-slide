the engine-supplied EvidenceIR work packet and the media plan. Read the required
context image and crops before responding.

Return only the typed TranslationPatch fields. Preserve every source region,
number, date, unit, table cell, entity, visual relationship, and the exact
degree of managerial commitment. Use the closed commitment and speech-act
enums. Use exactly one provenance state for decision-bearing semantic items:

is insufficient, set `unresolved` and explain why; unresolved content must not
be presented as fact. Executive claims require evidence IDs. Do not invent
source geometry, OCR text, numeric facts, coverage, or required-region inventories.
